A CONSTRUCTED ENVIRONMENT

A choice has a history.

Five agents encounter the same reward schedule. Halfway through, apple and music rewards switch. See what memory and learning change.

Synthetic, by design. These are authored mechanisms, not a biological model. Stochastic policies use seeded exploration. Deterministic policies use no random draws and fixed tie rules. Each learner has a matching control with learning disabled. A deterministic mechanism is not evidence that a bird is deterministic.
A PRACTICAL STARTING POINT

Listen carefully.
Keep the evidence.

1 / Declare the question

Use a subject code, choose available symbols, and define exactly what would count as corroboration. Keep the criterion concrete: for example, selects the requested item and eats at least three bites. Decide trial limits before observing.

2 / Commit before the response

Record the actual display order, prompt, context, brightness values, and context weights before the bird responds. This app records your existing setup; it does not operate or rearrange a speech board. Control predictions lock at commitment.

3 / Record what happened

Enter the observed selection, latency, initiation, and corroboration. Unknown is distinct from no. Describe behavior separately from interpretations. A media reference is a filename or timestamp; videos are not uploaded or analyzed by this app.

4 / Review and share

JSON exports contain the complete event chain and control predictions. CSV is a flat observation table. Save the receipt separately to check later changes. Pending predictions are hidden in the app, but the full export reveals them.

What the controls ask

Uniform chance: equal probability across available symbols.

Position: a fixed preference for the first recorded position.

Brightness: selection probabilities based on your recorded luminance proxy.

Past-choice frequency: only earlier recorded responses, with a one-count prior.

Prompt echo: favors the last available label occurring in the prompt.

Recorded context: uses your precommitted ratings. This is a subjective baseline, not independent semantic ground truth.

Deterministic alternatives

Four additional controls choose exactly one symbol: the first position, the brightest symbol, the most frequent earlier selection, and a context learner. Ties use the first recorded display position.

The context learner starts with values zero and updates earlier assessed selections by value += 0.25 × (reward − value), where corroboration yes = 1 and no = 0. It matches context text after normalizing case and whitespace. Unknown and nonresponse outcomes do not train it. These human assessments may contain observer bias. It does not understand the context text.

What the scores mean

Brier score is the sum of squared errors across the available symbols; log loss is −ln(probability assigned to the observed selection). Lower means a better predictive match. Deterministic mismatches have Brier score 2. Their true log loss is infinite; the displayed log loss floors probability at 10⁻¹⁵ (about 34.539 for a mismatch), with zero-probability responses counted separately. Different choice counts affect score ranges. These are descriptive scores, not significance tests or proof.

Participation comes first

Withdrawal or observed distress closes the session. Two consecutive nonresponses also end it. Nothing here asks you to isolate, frustrate, or deprive a bird. Work with the bird’s caregiver and the study’s approved protocol.
