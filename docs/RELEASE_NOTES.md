Bird Voice Lab 0.1.0 is the first runnable release of Ellie's Voice Lab.

Download **BirdVoiceLab-0.1.0-Windows.zip**, extract the entire ZIP, then open **BirdVoiceLab.exe** inside the folder. No Python installation is needed. Use **Explore a synthetic example** to try the notebook first, and **Quit application** to stop it.

This release includes prospective bird observation records, six transparent comparison controls, JSON/CSV exports and integrity receipts, plus a separate learning-agent sandbox with replayable traces. Records stay on the local computer.

Validation: 10 automated tests, a complete browser workflow, and a browser check of the packaged executable passed on Windows 11. The Windows build is unsigned. macOS and Linux can use the Python source, but were not tested for this release.

This version uses manually entered observations and does not automatically recognize bird vocalizations. Scores describe prediction fit. Saved entries are immutable; corrections and later adjudication require external annotations.
